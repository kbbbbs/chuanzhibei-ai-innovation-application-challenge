## 历史检查方法与边界

通过 `git rev-list --objects --all` 读取 5930 个可达对象名，对其中 2651 个不大于 10 MB 的文本 blob 检查已知私有值、API Key 样式、GitHub Token 样式、私钥块和凭证 URL。仅记录路径、类别、计数和 blob 定位，不写密钥值或密钥散列。历史二进制、不可解码文本及超过该上限的 blob 未做全文凭证扫描；它们也不会随新的根提交上传。

当前 XML 容器文档的可读 XML/关系文件也经过凭证检查；浏览器私有数据库和图片不能用普通文本扫描证明安全，因此采用明确排除和范围说明。`git count-objects` 另报告一份旧临时对象垃圾，审查未清理或修改它。
