# K03 人工验证：混合检索、版本与降级

日期：2026-10-30。对应 [实施与测试报告](K03-test-report.md)。使用自己的隔离教师测试库；不要为了验证故障而修改业务数据库向量。

当前K03代码已实现，但真实续验Top5为33/40（82.5%），尚未达到85%目标，且低于同题关键词对照35/40。以下步骤用于核验实际行为，不能替代质量验收或作为“语义更优”的演示结论。

## 1. 启动与已有资料升级

按 [K02 启动步骤](K02-manual-verification.md)重新构建并启动前后端。本轮V005只新增解析算法版本字段，不覆盖旧原件、页面或索引。私有Embedding配置继续使用 `Qwen/Qwen3-VL-Embedding-8B` 及现有独立密钥，不需要粘贴密钥到聊天。

如果资料已经完成K02解析，可以在“资料与出处”选择“重建向量索引”。该操作保留文字、页号、字符范围、公式、图片关联及原解析/分块版本，仅重算向量并切换新索引。若旧页本身尚未升级公式/图文能力，先按K02要求重新解析；重建向量不会修复OCR内容。

旧索引的解析算法标记可能为 `legacy-unverified`，重建向量会原样保留，不能冒充新版解析。重新解析后才有新的解析算法标记。

## 2. 同义表达与来源

选择一个已建立向量的库，检索课件中的具体概念。例如把“梯度下降”换成“训练时怎样沿着减少误差的方向调整参数”，或把“过拟合”换成“训练样本上表现很好，换数据却变差”。

检查本次状态显示“语义＋关键词”，命中片段确实含相关依据。打开出处，核对页号、资料版本、解析修订和索引编号；公式和图片仍能正常核验。不同文件类型没有可靠页码时不应编造页号。

排序得分不是概率或回答置信度；同义召回命中也不代表回答内容正确。K03真实统计以冻结题集结果为准，个人临时提问不替代验收题。

## 3. 实际模式与降级

接口 `POST /api/rag/search` 继续兼容 `knowledgeBaseIds/query/topK`，新增：

- `actualMode`：`HYBRID`、`KEYWORD`、`NONE`。
- `degradedReason`：例如 `EMBEDDING_UNAVAILABLE`、`NO_COMPATIBLE_VECTORS`、`INCOMPATIBLE_VECTORS`、`PARTIAL_VECTOR_COVERAGE`、`EMBEDDING_DISABLED`、`EMBEDDING_NOT_CONFIGURED`、`EMPTY_INDEX`、`EMPTY_QUERY_TERMS`。
- `indexVersions`：本次实际扫描范围的索引快照，含文档/解析修订、模型/指纹、维度、归一化和解析/分块版本。这不是全部“入模片段”的清单；回答引用仅对应实际选中的来源。

空库或无有效检索词不应冒称已经执行语义召回。部分片段缺向量时，可以仍为 `HYBRID`，但必须显示部分覆盖提示；向量服务不可用时应明确 `KEYWORD` 降级，仍保留真实关键词结果。

需要人为验证故障时，另开隔离演示进程，临时关闭 `RAG_EMBEDDING_ENABLED`，或使用测试端点；不要覆盖正常私有配置。重新启动后检索，应显示实际仅关键词。缺失/损坏/错维度/错模型向量的更多边界由隔离自动测试验证，不能靠改业务库制造演示效果。

## 4. 版本与权限

在隔离库中新建/替换资料，或重建向量索引后，重新搜索应看到新索引。旧引用若不再对应当前来源，应明确提示版本变化；不能把旧图片或旧版本号拼到新片段。

检索在模型请求之后会再次核对授权和有效索引快照。若期间权限撤销或索引切换，请刷新重试，不能混合返回前后两个版本。另一个教师或学生未获该通用私有库权限时仍应被拒绝。课程课时授权继续由K05专门验收。

## 5. 参数与边界

默认 `RAG_RETRIEVAL_RRF_K=1`、`RAG_RETRIEVAL_CANDIDATE_LIMIT=20`，由原10条调参题的预登记15组配置选出，分别控制RRF平滑和每通道候选数量。若本机曾手工设置旧60/100，会覆盖默认，需在隔离演示进程核对。不要凭验收题表现反复改参数；调参与验收应分开。每次请求最多2万候选片段，输出最多20条；当前向量存取抽象是读取/精确扫描接口，尚未迁移到外部向量数据库。

无答案查询也可能返回相似候选。K03不把RRF得分当可答性阈值，不能仅凭“有命中”就生成答案；K04的拒答与引用支持度仍须另外验收。

本轮测评使用部分可核验课程页及历史真实OCR，缺失页会计数；不等于334页已全部重新解析或语义覆盖完成。详细范围、题集、失败记录和最终成绩见测试报告。

## 6. 自动评测复核边界

普通后端回归运行`mvn test`，真实接口评测按条件跳过，不会自动计费。开发评测入口`K03RetrievalLiveTest`显式设置`K03_LIVE_RETRIEVAL_CHECK=true`，`K03_RETRIEVAL_RUN=tuning`只读原10条调参题，`followup`读取已冻结续验；后者有单次运行保护，已有报告不允许覆盖重跑。该50题现在已观察，不能继续用来挑选参数。

课程评测依赖被忽略目录中已有的K02扫描/公式原始OCR、K03补充OCR及精确真实向量缓存；它们含原课件内容，不公开进仓库。执行`mvn clean`会删除这些复现前提，需要从私有备份恢复或重新做真实OCR并记录来源，不能用题目答案填补。公开报告仅包含来源ID、散列、版本、计数和成绩。教师后续独立验收应另定真实问题，先冻结，确认所有预期来源都在有效索引中，再评分。
