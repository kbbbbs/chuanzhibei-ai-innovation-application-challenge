原始需求：你先做一个可视化的知识图谱功能，可展示，能拖动，能显示关系，先在一个章节的基础上做

交付
基于《第2章-机器学习概述-okk.pdf》整理 15 个核心知识点、14 条知识关系及 3 条学习顺序建议。保留来源文件 SHA-256、PDF 页码和说明；示范覆盖核心概念，不宣称完整覆盖全部学习类型。资料整理与学习建议明确区分，学习建议待教师确认；没有冒称模型自动抽取或教师已审核。
Vue Flow 实现节点拖动、连线跟随、关系名称和方向、点击节点/边查看详情、搜索定位、关系类型筛选、放大/缩小/适应视图、恢复布局、键盘选择及窄屏布局。
位置保存在当前页面状态；选择和关系筛选不重建布局。刷新页面恢复预设布局，没有实现跨设备保存或教师编辑发布流程。
正式入口：/chapter-knowledge-graph，沿用登录及角色边界；教师知识库和学生智能学伴增加“体验章节知识图谱”链接。
本地预览：http://127.0.0.1:5173/chapter-knowledge-graph-preview，独立使用同一组件和示范数据，无需后端或登录。路由仅在开发环境注册，已检查生产构建不含该预览路径；没有给正式功能加匿名入口。预览服务绑定 127.0.0.1，没有部署到外网。
旧 /knowledge-graph 和知识库 API 保留。没有把章节示范作为任意 kbId 的检索结果，也不读取其他用户的课程/私有资料。

8. 数据静态核验：节点/关系 ID 唯一、关系端点有效、页码在 1–36 内、源文件 SHA-256 一致；见 data-check.json。这不代替教师语义审核。

人工验证
打开本地预览。拖动“损失函数”，观察相连线移动；选择“模型”或切换“知识关系”，检查刚才的位置不变；点击“恢复布局”返回预设位置。
点击“学习准则 → 损失函数”的连线，查看关系说明和来源页码；切换“学习建议”，查看 3 条带方向的建议及待教师确认标记。
搜索“梯度”，选择结果查看节点及详情；输入不存在的词显示空结果。使用放大、缩小及适应视图检查视野控制。
在应用登录后，教师从知识库管理、学生从智能学伴的“体验章节知识图谱”进入正式页面。
