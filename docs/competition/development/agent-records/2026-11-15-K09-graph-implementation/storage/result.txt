实现
采用 Boot 3.5.16 管理的 Neo4j Java Driver 5.28.13，增加 GraphSlice 与 Neo4jGraphRepository。
生产调用使用 Spring Boot 管理的共享 Driver，Session 按调用建立和关闭，在事务内完成结果转换。
图谱版本按 graphId + graphVersion 隔离，节点使用应用 ID，唯一约束保护并发。
相同版本、相同规范化内容可重复投影，不重复产生节点和关系。相同版本不同内容返回 409。
读取、邻居、路径有硬上限、超时及截断标记。先修路径只沿 PREREQUISITE_FOR 方向。
查询参数绑定，关系标识来自固定枚举，读取结果不包含数据库内部 ID。
配置默认 rag.graph.enabled=false。关闭或数据库不可达时返回明确 503。
