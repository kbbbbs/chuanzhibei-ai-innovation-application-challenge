K09 课程知识图谱实施
本轮用户原文：按照这个方案去实施
方案依据：docs/competition/development/K09-knowledge-graph-integration-plan.txt
工作区已有上一轮静态章节示范及评估记录，继续增量开发。

故事与验收
1. 教师为一个真实章节导入候选实体关系，后台保存草稿，审核后发布至 Neo4j。重启可读，重复任务幂等，失败可重试。
2. 学生在有效课程资料授权下查询图谱、邻居、路径和原文证据。未发布、撤权、过期版本及其他课程不能泄露数据。
3. 课程页面以 Cytoscape 显示可拖动圆形知识网络、关系名称和方向，支持搜索筛选、展开、详情、路径和空/失败状态。
4. 自动抽取使用既有非GPT模型抽象返回候选，校验真实证据后交给教师审核。

执行方式
存储、后端、前端分配给三个子 Agent，根 Agent 负责真实课件导入工具、集成与最终验收。各子 Agent 要求单独导出真实会话，显式排除 fork 前缀。记录不包含隐藏分析或真实密钥。缺失操作不得虚称完整。
各模块先写有意义的失败测试，再实现和回归。根会话从本轮真实需求行538导出。记录为指定时刻快照。
