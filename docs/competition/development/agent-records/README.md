# 开发 Agent 过程记录

用户于2026-10-21确认：先记录开发过程，不增加产品运行日志。本目录保存真实会话的脱敏快照、工具操作与验证结果，用于后续整理10037/10039参赛材料。

## 导出

在项目根目录调用 Python（可替换为本机已安装的 Python 3.10+ 路径）：

```powershell
python scripts/competition/export_agent_development_records.py `
  --session-file '实际的 Codex 会话 JSONL 绝对路径' `
  --output-dir 'docs/competition/development/agent-records/2026-10-21-task/root' `
  --since '2026-10-21T00:00:00+08:00' `
  --private-env-file '.env.local'
```

`--since` 为包含边界的真实事件时间，必须带时区；导出日期不替代开发日期。子 Agent 的内部工具操作必须从该子 Agent 自己的会话另行导出到独立子目录。根会话中的委派提示和回复不代表已经捕获子 Agent 的全部操作。

子会话开头可能重放父会话历史，并带上新会话时间；不能仅凭时间筛选把这些步骤算作子 Agent 执行。导出子会话时必须显式指定 `--start-line`，定位到真实任务开始边界；未指定会拒绝导出。边界由操作者根据实际 `task_started` / `turn_context` 及委派消息核实，工具不使用不可靠的自动猜测。比如本轮 `/root/development_recording` 会话实际 `task_started` 为229行，原始委派消息为235行，应使用 `--start-line 229`。清单会记录所选边界与剔除的继承前缀行范围。

每次输出三个文件：

- `records.jsonl`：完整的已筛选、已脱敏记录，保留真实时间、源行号、会话、工具名称及 `call_id`。
- `records.md`：便于阅读的同一快照；超长内容明确标为节选，完整脱敏内容仍在 JSONL 中。
- `manifest.json`：源快照 SHA-256、读取大小、导出范围、显式任务边界、继承前缀剔除范围、计数、解析损坏行、无效时间行、跨范围缺失调用及脱敏方法。

导出只保留用户原始提示、Agent 的 commentary/final、可见委派消息、工具调用和输出。隐藏分析/推理、系统/开发者指令、加密字段以及已识别的内嵌上下文/摘要不导出。工具输出中 JSON 编码的内部字段也先解析过滤。正常可见用户 JSON 提示不按字段名删减。

密钥从当前进程环境及显式指定的私有 env 文件收集，仅用于内存脱敏；原值、原始会话文件及私有 env 文件不复制到记录目录。另对 Bearer、sk-key、凭据赋值、URL用户信息与敏感查询参数脱敏。公开前应核对输出，不应把“已运行脱敏”当作任意未知格式秘密都不可能出现的保证。

这是显式快照导出工具，没有安装平台自动钩子。任务开始、重要验证节点和最终反馈前应刷新；最后一次导出之后的新调用和最终回复，须在下一次刷新时补入。文件解析完整仅指此次读取没有损坏 JSON，不代表所有开发步骤或子会话都已齐全；源输出已被截断或缺失的部分不会补造。
