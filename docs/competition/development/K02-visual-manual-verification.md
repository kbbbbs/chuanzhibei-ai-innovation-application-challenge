# K02 图文增量：人工验证

日期：2026-10-28。结果以 [测试报告](K02-visual-test-report.md) 为准。复验用自己的教师测试库，保留原始课件。图片、公式与题号关联都需要对照原页，处理就绪不代表教师审校完成。

## 1. 启动及升级旧资料

按 [原 K02 启动方法](K02-manual-verification.md)重新构建并启动后端和前端。数据库自动增加 V004 私有图像资产表，旧原件和历史解析保留。OCR 继续使用已有独立配置；默认无需新增密钥。

以资料所有者教师进入知识库“资料与出处”。旧结果应提示尚未整理插图，点击“重新解析全部”，或先对代表页“强制识别本页”。重新建立向量索引不会重做布局识别和裁图。限定页重试只升级选定页，其他历史页仍可能需要重新解析。

## 2. 真实课件核验

建议先检查 `D:\PPT\人工智能`：

| 位置 | 检查内容 |
| --- | --- |
| 第4章第10页 | 激活函数曲线应有局部图；检查坐标轴、图例和边界有没有裁掉；公式仍有独立源码与排版 |
| 第5章第14页 | 核对卷积单核/多核、三维结构和灰度/RGB图示；没有可靠图框时应显示“原页参考图，未定位插图” |
| 第3章第23页 | 公式与原页参考图可以同时保留；整页图不能冒称检测到独立插图 |

打开“逐页核验”，查看图片与关联原文。局部图的框来自模型真实返回并经范围检查；题号和相邻文字属于待核验的关联。确认当前源版本和解析修订正确。切换页面后应换成对应图片，不能保留上页旧图。

若 OCR 只给了图框、没有可用文字，允许保留图像来源参考，界面显示“原页图像参考”；这段来源说明不是 OCR 正文。若图片又因配额、裁剪或渲染失败而未保存，则该位置必须失败，不能只把占位说明当成可用教材内容。

每页最多 6 个可靠局部图，每张 PNG 最多 1 MiB；同一文档版本/解析修订累计最多 32 MiB。受限时会显示核验问题。大页、细小文字或不规则布局需要对照完整原件。

## 3. 分题与关联

上传一份包含两道编号题的测试 PDF/PPTX，题号采用清楚的行首 `1.`、`2.` 或“第1题”等形式，每题包含题干、选项、公式和配图。图文原文应能在“按题号整理（待核验）”展开查看，编号保持原样，显示关联插图数量。

检查题2的插图不会关联到题1；长题干跨多个检索片段时仍能带出本题配图。公共页标题不是所有图片的唯一定位点。没有可靠题号或图注时会保留页级关联，不能据此宣称语义分题准确。题号重复、跨页续题、复杂嵌套小问、手写题均需人工核验。

## 4. 检索引用与回答

在知识库中用页内标题、原文术语或题干提问。命中片段应出现“含图”；打开出处可见公式、图片、关联文字和源文件入口。当前先做文本/向量命中后携带相关图片，不表示已完成图搜图或独立视觉向量召回。

默认流程：相关私有图片 → DeepSeek-OCR 解读/可见文字转录 → 文字回答模型。回答状态应提示图像经过 OCR 解读、仍需核验。没有可用观察、读取超时或失败时，应明确尚未完整读取，不能声称已经理解图中关系。

曲线/统计图的模型估算数值不能自动当成原文数据。应检查系统是否拦截生成的定量表，或明确回退到可见文字，并保留原图。不要仅因为返回非空文本就接受其数值结论。

若之后配置了支持图片输入的非 GPT 回答模型，可设置：

```powershell
$env:RAG_CHAT_ATTACH_IMAGES = 'true'
```

然后重启后端。此开关会把实际 PNG 附给已配置的回答模型；它不会让不支持视觉的模型自动获得看图能力。默认保持 `false`。默认最多读取 2 张去重图片、合计 2 MiB，每图 15 秒；可通过 `RAG_VISUAL_TIMEOUT_MS` 调整，应用限制在 100–30000 毫秒。多图未读完须有提示。

## 5. 权限、版本与取消

- 关闭引用抽屉或切换页面，原图片应被清除；重新打开按当前片段重新获取。
- 用另一个教师或未授权学生请求同一图片，应被拒绝。图片需要 Bearer 鉴权；响应 `private, no-store`，不把令牌放进 URL，不使用公共 uploads 图片。
- 回答读取期间撤销用户权限或切换有效来源版本，不能继续使用失效片段或与片段无关的图片。
- 替换资料处理失败或取消时，旧可用索引仍按原规则保留。新旧图片分别绑定版本和修订，不能拿旧图冒充新稿。
- 取消生成应中断图像读取与后续回答；不显示“已完成”。删除自己的测试文档后，派生图片随资料清理。

此通用知识库入口沿用所有者权限；带课程上下文的学生资料授权仍按既定课程任务验收，不能通过猜图片 ID 获得访问权。

完整后端回归、真实 MySQL、真实 OCR 以及模拟浏览器测试的实际范围见报告；没有把受控页面数据称为全业务真实端到端验收。
