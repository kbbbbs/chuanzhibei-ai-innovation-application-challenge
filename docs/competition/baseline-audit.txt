1. 比赛约束与用户要求的区别
10039：个人赛，原创真实全栈作品；保留细粒度 Git 历史、至少 3 条核心功能完整 AI 对话链、10 分钟复现说明；5–8 分钟 1080p MP4，其中至少 2 分钟展示 AI 协同过程；技术文档 PDF 不超过 30 页。
10037：1–3 人同校团队，允许单人；作品必须是 Web 应用，AI 是核心而非附属功能；提交有评委访问权限的代码仓库、完整 Git 历史、README、环境说明、5–8 分钟 1080p MP4、PDF 不超过 30 页。
10037 公网演示是可选加分项。RAG、多模态、Agent、MCP/工具集成是详细评分维度，不是必须同时完成的功能清单。
用户明确要求：当前 WeKnora 接入不计为本项目自有 RAG，需重建并覆盖实际使用到的所有主线调用。此要求不能混写成赛事禁止使用第三方基础库或模型 API。
10040 规定的科研 PDF 阅读器、541 页教材、语义版本去重等不属于本轮范围。

2. 本项目已有主体
前端为 Vue 3 / Vite / Pinia / Vue Router，后端为 Spring Boot / MyBatis / MySQL。
课程、章节、课时、题库、学习、考试等业务模型和权限属于本项目。
Agent 的历史上下文裁剪、系统提示装配、schema 驱动规划、读工具、写操作确认和执行属于本项目。
备课的配置→骨架→课时→题目→审核→发布工作流属于本项目；t_ai_preparation 持有 teacher_id、状态、JSON 草稿、发布课程 ID 和版本号。
PDFBox / POI / Tess4J 已作为基础依赖存在；OcrService 是本项目辅助实现，但不能据此认定已拥有独立解析索引系统。

3. 外部 RAG 的真实依赖范围
前端 src/api/knowledgeBase.js 的知识库 CRUD、列表、上传、检索、会话、内容、文件、图谱全部指向 /api/weknora。
WeKnoraController 是外部服务代理，不是本地知识库实现。
WeKnoraServiceImpl.search 调用外部 /api/v1/knowledge-search。
searchKnowledgeLocally 虽包含 locally 名称，仍通过 HTTP 获取 WeKnora 文档摘要后计算标题/摘要关键词分数；无本项目持久化索引，也不是独立的向量检索。
本地 schema 在改造前只有 Agent 外部 knowledge_base_ids 和备课外部 owned_knowledge_base_id / knowledge_base_ids_json，无自有 KB/document/chunk/index 表。
Agent：AgentPromptAssembler → WeKnoraKnowledgeContextProvider → WeKnoraService.search；知识库不可用会返回空上下文继续普通生成。
Agent 上传：AgentDefinitionService.uploadMarkdownDocument 调外部 uploadFile，且将绑定 ID 强制解释为 WeKnora UUID。
备课：PreparationService 上传时调用外部 createKnowledgeBase/uploadFile；生成大纲、课时、题目都调用外部 search；资料准备状态调用外部 listKnowledge。
题库：QuestionService.extractQuestions 外部上传 PDF、创建外部会话、外部 chatSync；generateFromKnowledgeBase 外部检索后才调用本项目模型。
因此不能只更改知识库列表页面或提供一个新 search 接口，就认定已经摆脱 WeKnora。

4. 文档、片段和出处颗粒度
改造前 SourceFile 只有 name / knowledgeId / parseStatus / parseProgress / errorMessage。
改造前 AgentChatResponse 只有 session/message IDs、content、pendingAction、createTime，没有结构化 citations。
备课课时只有 contentMd，题目只有 analysis 等业务字段，没有记录本次生成所用 document/chunk/page 的真实来源快照。
学生 KnowledgeBase.vue 已有引用 UI，但 fillCitationFallback 在回答完成后额外检索 3 条补引用。它只能证明事后检索获得片段，不能证明生成时实际使用了这些来源。
改造目标：生成时选择实际授权的片段；每个片段返回真实 documentId、chunkId、kbId、标题、页码/片段序号、文本和检索方式；答案引用只使用本次上下文，保留生成和历史的一致性。
备课/题目：确定性保留“生成参考资料（供教师核验）”及本次实际参考摘录；这种参考列表不等同于每句答案或每道题已经事实核验。
文字资料没有可靠页码时必须为空，不得人为补成第 1 页。
关键词检索与语义向量检索需分别说明；配置了模型不等于实际调用成功。降级必须明确显示。

5. 权限与异步任务
全局登录验证只是登录边界；改造前 WeKnoraController 的 KB CRUD、上传、检索、会话、原文件下载没有本项目 owner/course 资源授权。
统一 WeKnora API Key 不会自动形成学生、教师之间的隔离。
改造前 AuthInterceptor 豁免 /api/weknora/local-file/**，该本地文件代理不能直接用于私有课程资料。
资料授权必须贯穿上传、绑定、列库、检索、片段查看、原文件下载、删除、Agent、备课、题库。
备课工作在 preparationTaskExecutor 中运行；UserContext 是 ThreadLocal，不随任务自动传播。异步检索应显式使用 project.teacherId，并在入队前和工作线程内重新检查绑定权限。
题库的资料访问主体是当前操作用户，teacherId 参数用于题目作者；管理员替教师课程出题时，不能将教师 ID 误用为当前管理员的资料授权身份。
绑定的外部旧 ID、已删除 KB、不可读私有 KB 必须明确失败；不能静默删除绑定继续生成。
有资料但检索/读取失败必须中断并允许重试。整体课程备课没有关键词命中时可明确按授权文档顺序选取前部片段；不可把这种摘要选取称为问题相关性命中。

7. 优先验收门槛
在完全不启动 WeKnora 的条件下，完成本地资料上传→解析→片段检索→有出处问答；教师资料→备课大纲/课时/题目→审核发布；原文 PDF→题目提取；知识库→题目生成。
真实资料重启后仍可使用，删除后不能再检索，外国 owner 不可读私有材料，分享撤销在异步任务里重新生效。
有资料而索引失败不调用生成模型；无资料的普通课程配置生成与有资料的失败不得混淆。
完成上述基线后，再按评分收益增强语义/混合检索、流式交互、前端视觉、量化教学效果、可选公网演示。
