## 发布录制步骤

1. 学生打开“我的班级”，初始只显示两门已发布课程。
2. 教师编辑ID1003912的预置草稿，可修改标题和内容，然后执行课程发布。
3. 学生刷新“我的班级”，应出现刚发布的课程，随后进入课时1003953。
4. 如需重新录制发布片段，教师把这门录制草稿改回草稿状态，学生刷新后它应隐藏。再按真实发布步骤录制。

系统中的教学班绑定具体课程。因此本次预置的是“已有草稿、教学班及学生成员”，应按真实状态介绍。另行新建课程时，需要为新课程建立教学班并加入学生，或者由教师明确调整班级课程关系。

## 启动与保留数据

从项目根目录执行，JDK路径换成本机实际目录。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/competition/start-recording.ps1 -JavaRuntimeHome 'C:/Users/KBS-ROG/.jdks/openjdk-24'
```

首次构建后可加 `-SkipBuild`。SQL只新增缺失的合成记录，重启保留教师已经修改的正文、课程标题、发布状态、账号密码及成员状态。上传资料与索引亦存储在录制专用目录中。

资料状态、问答生成、来源和模式应按实际服务结果录制。当前模型配置经本机私有环境或 `.env.local` 提供。
