# 合成教学示例

`gradient.md` 为 UTF-8 Markdown，可在教师“知识库管理”页面新建资料库后上传。它用于检查文字解析、课程资料授权、课时选文提问、来源展示和授权撤销流程。

教师可将文件末尾“可用于课时正文的文字”复制到新课时正文。学生可以选中“学习率影响每次更新的步长”，点击“解释这段”，提问“学习率过大会怎样”。

建议另问“这个数据集最佳学习率是多少”。本文没有提供具体数据集结果，按实际回答观察界面状态。无需将这次人工演示记录为检索质量评测成绩。

本示例不带分页。来源界面应显示实际片段位置，页码以系统实际解析结果为准。OCR 演示另使用已获授权的 PDF 或扫描资料，并在录屏中保留实际处理状态。
