# 梯度下降学习示例

这是一份为本次课程 RAG 复现编写的合成教学资料，允许随本提交包复制、上传和演示。本文没有取用实际课程讲义或学生个人数据。

## 学习目标

理解梯度下降更新参数的方向、学习率的作用，以及训练损失和测试表现的区别。

## 梯度下降如何更新参数

梯度描述损失函数在当前位置增长最快的方向。梯度下降沿负梯度方向更新模型参数，希望逐步减小损失。设当前参数为 θ，学习率为 η，更新可写为 θ_new = θ - η × ∇L(θ)。

## 学习率的作用

学习率决定每次更新的步长。学习率太小，模型可能需要更多次迭代才能到达较低损失的位置。学习率过大，更新可能越过较低损失区域并产生振荡，甚至无法稳定收敛。学习率需要结合数据、模型和优化过程选择。

## 训练与测试

训练损失用于观察模型在训练样本上的拟合情况。测试表现用来观察模型对未参与训练的数据的泛化能力。训练损失下降时，仍应单独检查测试表现。

## 资料范围

本文介绍基本概念，没有给出某一具体数据集的最佳学习率、实验准确率或训练曲线。

## 可用于课时正文的文字

梯度下降沿负梯度方向更新参数。学习率影响每次更新的步长。训练损失和测试表现需要分别观察。
