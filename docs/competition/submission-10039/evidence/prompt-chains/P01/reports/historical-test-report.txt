以上观察是 Agent 对原页和实际结果的抽查，不是教师签字审校，也不是所有扫描副本逐项人工验收。所有 OCR 页仍标记需要核验。结构校验只能检测分隔符、括号、环境、长度等问题，无法自动发现一个语法正确公式中的漏 λ 或错误下标。不能让回答 LLM 自行“修复”后再当作教材原文。

本轮没有重跑全部 334 页及原先 20 页扫描集；那组数据保留为 2026-10-25 的历史结果。也没有进行数学等价性自动证明、逐字符准确率标注、真实问答模型的课程质量评测或人工审校发布。真实 OCR 测试按单次调用 120 秒超时；产品默认 60 秒，人工复验可通过 `OCR_TIMEOUT_SECONDS` 调整，不应把超时误当识别完成。

## 4. 真实失败与修正

1. 先写公式边界测试，旧分块会切开公式、文字层公式不触发视觉识别，5 项中 4 项失败；新增解析器最初为缺类编译失败。补齐后再测试持久化、上下文和引用边界。
2. 持久化/旧结果标记、问答长公式、Agent 上下文和公式内引用编号均有真实红灯记录；按小步修改转绿。普通图示 `D=3` 误触发公式路径，也先复现再修正。
3. 真实第一次生产链 11/12 就绪，第4章第23页截断。尺寸探针的 0.75 和 0.9 两档均正常结束，因此加入受限尺寸重试；不修改原件。
4. 真实第二次 9/12 就绪：普通识别已经截断，未进入只接受“无错误”返回的公式重试。修复截断分支，并结合原页数学字体直接选择公式模式。第三次 12/12 就绪。失败统计与最终统计分别保留，不覆盖失败历史。
5. 引用抽屉原来仅展示源码。功能红灯确认 `.source-formula .katex` 缺失后加入排版。曾有两轮浏览器失败是测试服务器停止导致连接拒绝，按环境失败保留，不能冒称业务功能红灯。
6. 最后补测发现表格内部保护占位未恢复，以及边界长公式与变量说明分离；分别修复嵌套还原和有限后文保留。尺寸重试抛服务异常时原始结果丢失的测试也先失败，再修为保留初次返回且不发布失败页。
