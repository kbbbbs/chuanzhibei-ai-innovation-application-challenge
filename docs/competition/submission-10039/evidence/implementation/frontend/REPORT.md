## 功能

- 学习页正文与笔记编辑器选文后提供“解释这段”，固定所选内容并切到课时问答，可移除选文。
- 问答携带当前 courseId、lessonId、独立 query 和 selectedText。首次直接请求流式问答，课程模式不创建私有库会话。
- 展示当前课程授权资料数量，支持课时历史、新对话、删除、停止生成和模型故障重试。切课时清除选文并阻止旧回调恢复内容。
- 共享 RagConversation 展示知识库及课时消息、公式、流式状态和来源。课程引用用课程授权的文档版本接口读取出处，保持原件下载入口受限。
- 教师资料列表增加课程授权与撤销入口，读取现有 /courses 列表，后端按教师身份过滤可维护课程。授权默认 readExcerpt=true、downloadAllowed=false。

## 失败与修正

首轮测试夹具仅拦截 /api 路径，课程原有接口使用 /courses，导致未加载正文。修正拦截范围后，确认旧页面缺少“解释这段”入口，测试在该步骤失败，再实现选文功能。
选文按钮初放右下角被已有浮动助手遮挡，实际点击测试失败后将其上移。
教师授权测试先按 placeholder、后按 combobox 点击，都受到 Element Plus 内部占位层影响，改为键盘 Enter 打开下拉，验证可访问交互。
前端初稿给普通私有库请求也带 selectedText 空串，根任务审查发现兼容问题后改为只在课程模式发送该字段，相关知识库回归通过。

失败输出保留在真实脱敏会话记录中。早期自动截图目录被后续运行复用，未宣称保存了全部失败图片。
