# 10039 本轮实施与验证

本轮依据用户确认的快速参赛计划，实施课时选文与课程RAG问答、三组Prompt链整理、固定20题实测及启动复现。现有四份后端资料核验改动的散列与开始时一致。共享工作区的前端核验组件仍可能由其他任务更新，本轮未覆盖其改动。

## 功能验收

- 课时正文和笔记选文可固定到问答卡片、移除或带着问题发送。
- 服务端按学生有效学习资格、当前课程、课时和已授权文档版本检索。停用课时或章节被拒绝。
- 纯选文解释显示selection模式。有资料和选文时使用course模式。检索失败与无证据分别处理。
- 课程会话范围、用户所有权、历史读取及生成输出重新校验授权。撤权阻断旧会话，可删除自己的旧会话后重新开始。
- 教师授权/撤销入口、共享问答展示、停止、新对话和历史恢复已接线。旧知识库请求兼容可空新增字段及空选文。
- V007可重复增量迁移保留旧会话，SQL参考同步到database/migrations。
