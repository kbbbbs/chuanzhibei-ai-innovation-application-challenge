## 已核对的行为

课程读取先校验有效学习或教学资格。课程请求禁止混入私有知识库 ID，课时必须属于课程。检索范围从 read_excerpt 授权及具体文档版本索引生成。检索前后、流式增量前、最终保存前均有课程范围重验。已存在课程授权后替换原文档仍使用被授权旧版本。

RagChatRequest 保留三参数构造器，旧 Java 调用能继续构造请求。V007 在聊天表创建后添加可空字段，迁移器按数据库列元数据判断是否需要添加，静态检查可重复执行路径。资源迁移和 database/migrations 参考文件均存在。

本轮未发现静态可直接确认的跨课程或教师私有库数据扩大问题。最终结论仍需根任务测试、真实请求与修复后复核。
