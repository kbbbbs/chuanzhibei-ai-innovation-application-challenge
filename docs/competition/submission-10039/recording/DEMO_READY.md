## 关闭电脑后重新启动

当前录制前端地址为24739端口，后端为18049端口，取材页为18739端口。已上传资料和课程编辑保存在 ai-learning-backend/data/contest-recording/ 中。

在项目根目录打开第一个终端，启动后端。JDK目录按本机实际位置填写，要求Java21及以上。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/competition/start-recording.ps1 -JavaRuntimeHome 'C:/Users/KBS-ROG/.jdks/openjdk-24'
```

另开终端启动前端。

```powershell
Set-Location ai-learning-frontend
$env:VITE_API_BASE_URL='http://127.0.0.1:18049'
npm run dev -- --host 127.0.0.1 --port 24739
```

再开一个终端，在项目根目录启动取材页。

```powershell
python -m http.server 18739 --bind 127.0.0.1 --directory docs/competition/submission-10039
```

后端启动入口会读取本机私有模型配置。SQL初始化仅补充缺失的合成记录，已经发布的课程状态会在重启后保留。后续在其他电脑准备环境时，可按[账号与关系说明](../demo/recording-fixture.md)初始化，再经教师上传流程导入资料。
