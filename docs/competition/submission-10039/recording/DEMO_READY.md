## 0:00至3:35的操作顺序

### 从零创建课程

1. 教师打开[课程管理](http://127.0.0.1:24678/courses)，点“新建课程”。
2. 课程名称填“人工智能基础”，课程分类选“人工智能”，难度选“入门”。简介可填“结合课程课件学习人工智能与机器学习基础，支持资料问答、检索和知识图谱探索。”
3. “导入课件”点“选择文件”，选择第2章-机器学习概述-okk.pdf。
4. 状态选“草稿”，点“提交”。进入课程详情，查看真实生成的章节和课时。

### 上传和授权全部8份RAG资料

1. 打开[教师知识库](http://127.0.0.1:24678/teacher-knowledge-base)，点“新建”，资料库名称填“人工智能基础课程资料库”，点“保存”。
2. 选中该资料库，点“上传资料”，逐份选择上表8份PDF。当前上传控件每次接收一份。
3. 等待真实处理结果，保留“部分可用”和待核验提示。部分页面失败的资料会列出相应页码，已有有效页仍可用于检索。
4. 以第二章第13页做“逐页核验”，对照图像聚类原页与提取结果。
5. 逐份点“课程授权”，选择新建的“人工智能基础”，点“授权阅读”。最后检查8份当前资料版本的授权状态。

### 关联人工智能一班并发布

1. 打开[教学班管理](http://127.0.0.1:24678/teaching-classes)，在“人工智能一班”行点“编辑”。
2. 课程选择新建的“人工智能基础”，点“保存”。已有学生成员会保留。
3. 回到[课程管理](http://127.0.0.1:24678/courses)，在新课程行点“启用”。
4. 学生刷新[我的班级](http://127.0.0.1:24678/my-classes)，看到课程后点“继续学习”。

### 学生智能问答

学生在可进入的课时右侧点“问答”，确认课程范围和授权资料数量，输入下列问题并发送。

> 监督学习与无监督学习有什么区别？请结合课件中的例子说明。

实际排练已生成回答并显示“关键词与语义联合检索”。可将回答滚动到两类训练数据的区别，以及图像聚类示例。参考资料可打开第二章第13页、第31页等本次实际命中片段，最终镜头以本次返回为准。

### 教师同问检索

教师回到同一资料库，打开“检索与验证”，粘贴上面同一个问题并点“检索”。展示实际返回模式、课件名称、页码和片段。第二章第33页对比表、第13页图像聚类、第31页监督学习定义均在原PDF中有对应内容，检索结果按当前索引返回展示。

### 可选知识图谱应用

1. 教师从新课程详情点“课程知识图谱”，新建章节图谱。
2. 标题填“图像聚类与无监督学习”，选本课程导入的第二章、对应资料库与第二章PDF，页码选13至13，创建草稿。
3. 展开“本章来源切片”，从当前切片核验并整理“图像聚类”“聚类”“无监督学习”3个节点，以及两条“属于”关系。
4. 按[图谱表单填写说明](graph/GRAPH_DEMO.md)填写名称、类型、解释并选择当前第13页依据，分别点“加入知识点”和“加入关系”。保存草稿，核验实体、关系和来源后审核发布。
5. 学生打开[章节知识图谱](http://127.0.0.1:24678/chapter-knowledge-graph)，选择新课程和已发布图谱，搜索“图像聚类”，展开相邻知识并查看第13页来源依据。
6. 路径起点选“图像聚类”，终点选“无监督学习”，查看经过“聚类”的2跳关系路径。

图谱段可单独剪掉。剪除后成片为6分35秒，AI协作段前移为2:40至5:40，共3分钟。

本轮自动候选抽取两次达到90秒超时。当前演示安排为根据真实课件人工核验、保存和发布图谱，再展示学生探索应用。表单依据下拉框会提供当前图谱的切片，具体可复制文字见[图谱录制说明](graph/GRAPH_DEMO.md)。

## 重启

在项目根目录启动当前开发后端，使用本机实际JDK目录。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/competition/start-local.ps1 -JavaRuntimeHome 'C:/Users/KBS-ROG/.jdks/openjdk-24'
```

另开终端启动当前开发前端。

```powershell
Set-Location ai-learning-frontend
npm run dev
```

私有模型与本机图数据库配置已放在被Git忽略的.env.local，启动脚本会读取它。现有关系数据保存在ai-learning-backend/data/contest-demo。教师从零建课时保留“人工智能一班”和学生成员，创建课程后再选择班级关联。
