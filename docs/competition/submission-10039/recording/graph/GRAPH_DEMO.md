## 教师创建图谱

1. 在“课程”选择正式录制时新建的“人工智能基础”，点击“新建章节图谱”。
2. 图谱标题填“图像聚类与无监督学习”。所属章节选择第2章“机器学习概述”，资料库与来源资料选择本次上传的第二章PDF。
3. 起始页和结束页均填13。确认资料已授权当前课程，点击“创建草稿”。
4. 展开“本章来源切片”，核对第13页正文。此处显示的是当前资料版本和解析版本的切片标识。

用现有表单创建全部内容，依据下拉框会列出当前图谱的真实切片。下表“解释”可直接复制。

## 可选的候选JSON模板

[可编辑候选JSON模板](GRAPH_IMPORT_TEMPLATE.json)保留了相同的3个节点和2条关系。需要批量导入时，先完成来源替换。

1. 从当前图谱的“本章来源切片”复制第13页切片标识。
2. 在编辑器中全局替换模板里的 `CURRENT_PAGE_13_CHUNK_ID`，共5处，替换值均为刚复制的当前标识。
3. 展开“批量导入与编辑”，将替换完成的JSON粘贴到“实体与关系 JSON”，或者通过“选择 JSON 文件”上传这个文件。
4. 点击“保存草稿”，逐项核对3个知识点、2条关系与原文依据，再审核发布。

模板以占位标识保留来源位置。正式粘贴前应完成全部5处替换，每次重新上传资料、重新解析或重建图谱时，都从当前图谱重新取值。图谱页“保存草稿”会校验这些来源是否属于本章的当前资料版本。

## 学生端操作

1. 打开“章节知识图谱”，选择“人工智能基础”和“图像聚类与无监督学习”。
2. 在“搜索知识点”输入“图像聚类”，点击同名搜索结果，再点右侧“展开相邻知识”。
3. 点击右侧“来源依据”的第13页，展示资料版本和原文。还可点击“聚类 → 无监督学习”关系，再打开它的第13页依据。
4. 路径起点选“图像聚类”，终点选“无监督学习”，保持默认关系范围，点击“查看路径”。页面应出现“已高亮查询路径”。
5. 点击图中的“适应视图”，需要时点一至两次“−”缩小，完整展示“图像聚类 → 聚类 → 无监督学习”两步关系。

这组查询在排练中的真实响应为3个节点、2条关系。该路径表达概念归属，讲解时可说“帮助理解知识点之间的联系”。
