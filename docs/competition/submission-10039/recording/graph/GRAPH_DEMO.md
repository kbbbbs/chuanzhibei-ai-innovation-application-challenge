# 新版课程图谱选录说明

本轮新版入口为[AI智学24679](http://127.0.0.1:24679/)，源码目录为D:/ai-learning-github-latest，后端8082。图谱55秒为可选镜头，可独立剪除。

## 教师入口

1. 打开本次新建的人工智能基础课程详情，点“课程资料”，再点子标签“知识图谱”。
2. 图谱范围可选“整门课程”。选章节时，选择对应章节和该章节资料。
3. 点击当前显示的“生成知识图谱”或“更新知识图谱”，记录本次进度。已有任务可按页面显示继续查看。
4. 生成完成且有可用节点、来源和关系后，再录制应用镜头。节点名称、数量和关系使用本次实际结果。

## 学生应用

1. 从我的班级进入本次课时，点击“知识图谱”。
2. 搜索本次已存在的一个知识点，打开真实节点详情。
3. 点“展开相邻知识”，查看当前关联。
4. 打开节点或关系的来源依据，展示本次课件页码与原文。
5. 在起点知识点和终点知识点中选实际连通的一对节点，查看关联路径并调整视图到可读位置。
