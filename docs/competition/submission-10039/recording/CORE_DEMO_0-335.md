## 排练检查

1. 课程导入采用第2章机器学习概述PDF，检查形成1章36课时并保留实际导入结果。全部8份课件均进入RAG资料库，逐份处理和授权。
2. 课程关联前显示“待关联课程”，教师保存班级关联并启用后，学生课程卡才出现。
3. 教师检索同问“监督学习与无监督学习有什么区别？请结合课件中的例子说明。”展示本次实际返回模式与片段。若索引处理尚未覆盖相应页，应先处理后再排练，或者按实际资料完成情况修订问题。
4. 选录图谱时，使用与本次新课程对应的真实来源。本次人工核验图谱包含图像聚类、聚类、无监督学习三个节点与两条属于关系，路径由图像聚类经聚类到无监督学习。
5. 选录图谱时，创建、人工核验和发布可分段录制，剪辑后保留同一课程、资料和版本，等待压缩处有字幕。
6. 完成所选片段的排练后，教师账号回到无课程起点，学生仍在“人工智能一班”。正式录制再次真实新建课程。
7. 完整旁白见[视频脚本](../VIDEO_OUTLINE.md)。本片段在3:35结束，后续按现有真实Prompt链时间轴录制。

选录图谱时，字段的可复制文字和逐项表单步骤见[图谱操作说明](graph/GRAPH_DEMO.md)。
