1. **识别公式页**：向 DeepSeek-OCR 发送原页图片，使用提示词 `Convert the document to markdown.`，让模型直接识别出带 LaTeX 的文档内容。这也是其[官方示例](https://github.com/deepseek-ai/DeepSeek-OCR#prompts-examples)提供的模式。

需要区分两种“结构化”：

| 含义 | 目前情况 |
|---|---|
| 文档包含标题、表格、LaTeX 公式等结构 | **已使用** |
| 模型直接按固定 JSON Schema 返回字段 | **当前没有启用** |
| 每条公式都有经过核实的图像坐标框 | **尚未实现**，当前提供原页和文本字符位置 |
