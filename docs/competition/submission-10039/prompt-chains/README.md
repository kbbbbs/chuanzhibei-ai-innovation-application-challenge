# 10039 核心 Prompt 链与复核索引

整理日期为北京时间 2026 年 11 月 17 日。依据官网“至少 3 个核心功能迭代时与 AI 交互的完整 Prompt 链”要求，本目录选取三条真实发生的缺陷反馈与迭代过程。每条均附用户原话、Agent 对外建议、修改与测试依据，以及自包含的脱敏 JSONL 快照。[官方赛道要求](https://www.boxuegu.com/matchTrack/detail/?id=10039)

| 主链 | 用户引导与产品目标 | AI 修改及验证 | 材料入口 |
| --- | --- | --- | --- |
| P01 公式识别与保留 | 用户人工核验发现公式文本化，追问方案，并要求补齐 K02 | 结构化保留、分块保护、专项 OCR 与排版，保留失败与修正 | [链条说明](P01-ocr-formulas.md) · [逐条可见对话](P01-visible-dialogue.md) |
| P02 逐页核验确认与编辑 | 用户指出无法确认或修改，并补充服务器页面与右侧抽屉位置 | 增加确认、编辑保存、索引修订，修正状态展示 | [链条说明](P02-page-review.md) · [逐条可见对话](P02-visible-dialogue.md) |
| P03 学习页与作业考试语境 | 用户明确提出课时布局拥挤和作业页面文案错误，要求改善并继续测试 | 响应式重排、业务文案及 API 切换，浏览器复验 | [链条说明](P03-learning-ui.md) · [逐条可见对话](P03-visible-dialogue.md) |

用户负责报告问题、设定目标和引导修复，Agent 承担代码修改及测试发现的进一步修正。材料逐项注明这一实际分工。官网要求未规定每个具体 Bug 都必须由用户再发一条纠正消息，本目录按真实互动呈现。

## 历史边界

本次从已归档的脱敏记录整理，保留各历史导出的实际截止范围。部分导出截止于最终反馈前，工具输出也可能已被原平台截断。当前未找到相应旧会话原件，未补写缺失内容。历史导出清单原样随附，完整性判断限于可见记录和已保存报告。

本文开发日期按北京时间表述，原日志 UTC 时间戳用于精确排序。P03 早期报告原文曾出现不一致的时区措辞，当前索引统一按 UTC 转换。

本轮仅核验材料，没有重新执行历史产品测试或模型调用。历史成绩均保留事件日期。参赛身份、原创权属和仓库完整演进历史按提交包的对应声明复核。
