## 最快复现路径

1. 按 [环境指南](ENVIRONMENT.md) 准备 JDK、Maven、Node.js 和私有模型配置。
2. 运行后端启动脚本，再运行前端。教师与学生演示账号均来自隔离演示库。
3. 教师创建课程、课时与教学班，加入学生，上传 `materials/demo/gradient.md`，将该资料授权给课程。
4. 学生进入课程，选中正文或笔记后点击“解释这段”，发送问题并打开出处。
5. 对照检索实际模式，验证新对话、历史、停止生成及授权撤销后的访问处理。

本机干净源码副本在共享依赖缓存条件下完成安装、构建、启动和登录，计时 89.631 秒。复现原始测量范围见 [计时报告](reproduction.md)，课程问答另有真实账号与浏览器联测记录。

## 结果口径

2026 年 11 月 17 日的小规模检索测量中，混合检索已标注来源 Top5 命中为 **17/20，85%**，关键词对照为 **18/20，90%**。36 页资料中 32 页进入索引，4 页公式结构失败，相关题目继续保留在分母中。来源页命中率、答案正确率和引用内容正确率按各自含义报告。

后端回归记录为 427 通过、19 跳过、0 失败。前端受控浏览器 51 项、公式渲染 8 项通过。教师、学生的真实课时问答与来源读取已完成联测。详细环境、测试归属和限制见技术文档及证据材料。
