真实场景与产品任务


---


课程资料常分散在课件、扫描 PDF 和教师笔记中。学生需要定位相关概念，教师需要检查资料处理结果并控制学习范围。本作品围绕课程资料整理、可追溯问答和课时选文解释组织交互。


| 角色 | 任务 | 系统行为 |
| --- | --- | --- |
| 教师 | 上传课程资料并检查处理状态 | 保留页、公式、出处及文档版本，支持逐页核验和课程授权 |
| 学生 | 针对课时正文或笔记提出问题 | 固定选文，自动结合当前课程已授权资料进行检索与回答 |
| 教师 / 学生 | 核对回答所用资料 | 展示命中的资料片段与页码，在授权范围内查看来源 |
| 开发者 | 维护可复现的 AI 开发过程 | 以真实 Prompt、失败、修正和测试结果记录功能演进 |


核心体验


教师上传资料并授权给课程。学生进入课时，选中不理解的文字后提问。系统根据课程资格及文档授权检索资料，显示回答、实际检索模式和来源。缺少可用资料时，已有选文仍可进入明确标识的选文解释模式。


页面延续既有课程管理、学习笔记和作业考试基座。参赛演示聚焦已经完成验证的课程资料与问答流程。备课和图谱的既有功能按照各自实际状态说明。


系统架构与职责边界


---


前端以 Vue 3、Vite 和 Element Plus 构成，课时与知识库共用问答消息组件。后端使用 Java 21 及以上版本、Spring Boot、MyBatis 和 JDBC。课程资格与私有资料权限在服务端校验。


项目自建 RAG 管理原件、解析任务、分块和索引。普通本机演示使用持久化 H2，MySQL 用于常规开发配置。核心资料问答可直接通过项目服务完成。


生成、规划、Embedding 和 OCR 各自配置。Embedding 采用 Qwen/Qwen3-VL-Embedding-8B，OCR 采用 DeepSeek-OCR。GPT 用于开发协作，产品运行配置采用已确认的非 GPT 模型策略。


知识图谱属于现有扩展模块，当前交付的章节图谱存储和展示依照 repository 版本说明。核心问答演示使用当前课程文档检索。


资料处理、来源与版本管理


---


资料管线


原件上传 → 持久化异步任务 → 逐页提取或 OCR → 保存可用页 → 公式与图文整理 → 分块 → 关键词及向量索引 → 授权范围检索。任务显示处理中、完成、部分成功、失败及取消等实际状态。


| 对象 | 保存内容与用途 |
| --- | --- |
| 原件与文档版本 | 私有文件、文件散列、文件名、页数与版本，作为重解析及授权版本的依据 |
| 页与解析修订 | 原始文本、OCR、采用的正文、页状态及公式信息，便于核对原页与识别内容 |
| 分块与索引版本 | 分块序号、页码、索引版本、Embedding 模型和维度，确保读取兼容数据 |
| 课程授权 | 课程、文档、具体版本及阅读/下载权限，按当前有效资格检查 |
| 会话与消息 | 用户所有权、课程、课时、资料范围快照和选文字段，支持历史及撤权检查 |


单文件支持 PDF、DOCX、PPTX、MD 和 UTF-8 TXT。单文件上限 20 MB，PDF/PPTX 上限 200 页。历史版本和部分失败状态继续保留，处理完成和内容准确性分别核对。


本轮样本的 36 页中有 4 页因公式结构检查失败未进入索引，详细页码和错误码随实测报告提供。


课时选文与 RAG 问答实现


---


| 输入或状态 | 处理方式 |
| --- | --- |
| 当前课程与课时 | 前端传入 courseId、lessonId，后端验证课时所属课程、发布状态及学习资格 |
| 学生选文 | 正文或笔记选文固定成卡片，作为 selectedText 单独传送，最多 1500 字 |
| 用户问题 | query 保持独立，检索时组合必要选文并限制长度 |
| 命中课程资料 | 按授权文档版本检索并生成回答，来源通过课程阅读接口访问 |
| 未命中且有选文 | 进入 selection 模式，页面显示“仅依据选中文本” |
| 没有资料也没有选文 | 返回补充资料或调整问题提示 |
| 切换课时或停止生成 | 取消旧请求，防止旧响应更新新的课时会话 |


最小接口扩展


POST /api/rag/chat 与 /api/rag/chat/stream 增加可选 courseId、lessonId、selectedText。原知识库调用继续兼容。GET /api/rag/courses/{courseId}/documents 提供当前可读资料。


课程模式由服务端确定资料范围。会话发送、流式输出、历史读取和最终保存前重新检查当前授权。文档替换后，旧授权继续固定原版本。
