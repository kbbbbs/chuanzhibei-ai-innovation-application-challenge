## 作品名称

## 选题方向

场景化轻量 RAG 知识库

## 作品简介

AI 智学面向课程资料分散、学生课时提问缺少上下文、资料开放范围难以控制等学习场景，提供课程知识库与课时学习助手。教师上传资料后，系统完成逐页解析、OCR 和索引，并将指定文档版本授权给课程。学生可在课时正文或笔记中选中文字，结合课程授权资料提问、查看出处并恢复历史对话。无检索资料但有选文时，界面明确显示仅依据选中文本进行解释。项目使用 Vue 3 与 Spring Boot，通过真实 Prompt 引导、失败复现、迭代修复和测试完成开发，配套提交核心 Prompt 链、架构说明及复现材料。

## 技术与 AI 协作说明

前端采用 Vue 3、Vite 和 Element Plus，后端采用 Java 21、Spring Boot、MyBatis 与关系数据库。资料处理使用 PDFBox、独立 OCR 适配和版本化索引，检索融合 BM25 与语义向量。Embedding 采用 Qwen/Qwen3-VL-Embedding-8B，OCR 采用 DeepSeek-OCR，回答生成通过独立配置的非 GPT 服务完成。开发过程中，人类提供业务目标、使用反馈和验收约束，Agent 生成或修改代码、复现问题、执行回归并留下脱敏记录。

## 实测结果说明

2026 年 11 月 17 日，固定一份 36 页课程 PDF 和 20 道预标来源题进行小规模测量，混合检索 Top5 来源页命中 17/20，关键词对照命中 18/20。32 页进入索引，4 页解析失败。后端 427 项通过、19 项跳过，前端受控浏览器 51 项通过。独立源码副本在本机共享依赖缓存条件下完成安装、构建、启动和登录共 89.631 秒。各项成绩的样本、版本、失败项及验证范围见提交报告。
