# Agent 能力矩阵

更新日期：2026-07-09

本文档用于对齐“项目已有功能”和“Agent 已接入功能”。状态说明：

- 已接入：当前 Agent 已有自然语言读查询或待确认写操作链路。
- 部分接入：已有部分工具或动作，但自然语言覆盖、权限、测试或前端入口不完整。
- 未接入：业务系统已有功能，但 Agent 还不能可靠处理。

## 已接入读查询

统一入口在 `NaturalLanguageQueryService`，聊天时由 `AgentPromptAssembler` 自动调用。当前已支持：

- 课程分类：列出分类、按分类名称或“某某类/某某相关课程”查课程。
- 课程：按课程名、简介、教师、难度查课程。
- 课程结构：查章节、课时、目录。
- 教学班：按班级名、学期、说明和课程候选查教学班。
- 通知：按标题、内容、通知类型查通知，遵循当前账号可见范围。
- 作业：查作业、提交情况、提交率、未交人数。
- 成绩：查成绩记录、平均分。
- 学习进度：查个人或指定学生进度、未完成课时。
- 考试：查考试安排、考试记录、考试统计。
- 试卷：按标题、说明、课程候选查试卷。
- 论文：按标题、摘要、会议/期刊、来源查本地论文。
- 教师申请：管理员按申请人、联系方式、原因、审核状态查教师申请。
- 导入状态：管理员或教师按最近导入、成功/失败状态查询导入相关操作日志。
- 课程统计：统计课程下章节数、课时数、教学班数、作业数。

读查询结果会尽量返回“解析范围”和“查询范围”，用于说明本次查了哪些候选、时间条件、数据表和匹配字段。
当分类、课程、教学班或学生候选不唯一，且当前问题需要明确对象时，Agent 会先返回候选列表要求补充信息。

不属于上述范围但明显是查询请求时，Agent 应明确返回“当前 Agent 尚未接入该类自然语言查询能力”，不再把未接入功能包装成“系统已查询但未找到数据”。

## 已接入写操作

写操作走“意图识别 -> schema 参数抽取 -> pending action -> 用户确认 -> 执行器校验 -> 审计日志”链路。

| 领域 | 动作 |
| --- | --- |
| 课程分类 | `course.category.create`、`course.category.update`、`course.category.delete` |
| 课程 | `course.create`、`course.update`、`course.status` |
| 章节 | `chapter.create`、`chapter.update`、`chapter.delete`、`chapter.sort` |
| 课时 | `lesson.create`、`lesson.update`、`lesson.status`、`lesson.sort` |
| 课程资源 | `course.resource.attach`、`course.resource.remove` |
| 教学班 | `teaching.class.create`、`teaching.class.update`、`teaching.class.status` |
| 班级学生 | `class.student.add`、`class.student.remove`、`class.student.status` |
| 通知 | `notice.create`、`notice.update`、`notice.status` |
| 作业 | `homework.create`、`homework.update`、`homework.delete`、`homework.submission.grade` |
| 考试 | `exam.session.create`、`exam.session.close`、`exam.answer.grade` |
| 试卷 | `exam.paper.create`、`exam.paper.update`、`exam.paper.delete` |
| 试卷题目 | `exam.paper.question.add`、`exam.paper.question.remove`、`exam.paper.question.update` |
| 题库 | `question.create`、`question.update`、`question.delete` |
| 成绩 | `grade.record.create`、`grade.record.update`、`grade.record.delete` |
| 教师申请 | `teacher.application.review` |
